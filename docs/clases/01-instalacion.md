# Clase 01 · Instalación y diagnóstico
Objetivo: distinguir instalación, implementación y puesta en marcha.

1. Inventariar Windows, PHP y MariaDB (`php -v`, `SELECT VERSION()`).
2. Encender Apache y MySQL desde XAMPP; abrir el proyecto y revisar README.
3. Leer `.env.example`; crear una base nueva con el instalador.
4. Entrar como ADMIN y luego CONSULTA; comparar el menú.
5. Ejecutar `tools/verify.php` y `database/verification.sql`.

Evidencia: captura de servicios, login, 13 tablas originales y consulta. Aceptación: 93 clientes, 830 pedidos, 2155 detalles y 13 FK sin modificar otra base. Diagnosticar una caída solo en un laboratorio desechable y con autorización; no hace falta apagar MySQL en esta instalación.
