# Clase 03 · Git, CI e infraestructura
Objetivo: relacionar herramientas con problemas concretos.

1. Ejecutar `git status`, `git log --oneline`, `git diff` y revisar `.gitignore`.
2. Crear una rama de práctica, modificar una guía y registrar un commit descriptivo.
3. Leer `.github/workflows/php.yml` y `Jenkinsfile`: instalación, lint y pruebas.
4. Interpretar `deploy/ansible`, `deploy/puppet` y `deploy/kubernetes`; explicar qué requiere un entorno externo autorizado.

Evidencia: dos commits de práctica, captura del historial y tabla herramienta/problema. Git versiona; CI ejecuta verificaciones; Ansible/Puppet configuran servidores; Kubernetes administra cargas de contenedores. Ninguna de estas plataformas es necesaria para operar XAMPP local.
