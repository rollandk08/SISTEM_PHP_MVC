# Clase 05 · Despliegue y recuperación
Objetivo: separar desarrollo, pruebas y demostración.

1. Comparar los tres ejemplos de entorno sin publicar secretos.
2. Ejecutar las pruebas en la base `_test`.
3. Crear un respaldo desde ADMIN; descargar y verificar esquema/conteos en la vista previa de restauración.
4. Ensayar una restauración exclusivamente en la base de pruebas. Confirmar recuperación del stock y revocación de sesiones.
5. Leer DESPLIEGUE_EDUCATIVO y preparar un checklist sin crear servicios externos.

Evidencia: archivos de entorno con secretos tachados, backup almacenado fuera del webroot, prueba de recuperación y plan de contingencia. El pase a una cuenta pública requiere autorización del propietario.
