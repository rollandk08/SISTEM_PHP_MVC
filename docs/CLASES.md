# Nueve clases ISAM

El ZIP entregado se utilizó como material de referencia curricular. Sus actividades se interpretan como ejercicios para el alumno, no como instrucciones para apagar servicios, publicar cuentas o ejecutar cambios destructivos en esta PC. No se modificaron las presentaciones originales.

| Clase | Fecha del material | Tema | Guía y evidencia |
|---|---|---|---|
| 01 | 19/10/2026 | Instalación | [Instalación](clases/01-instalacion.md): XAMPP, .env, login y conteos |
| 02 | 21/10/2026 | Migración | [Migración](clases/02-migracion.md): CSV, staging y conciliación |
| 03 | 23/10/2026 | DevOps | [DevOps](clases/03-devops.md): Git y lectura de pipelines |
| 04 | 26/10/2026 | Alcance | [Alcance](clases/04-alcance.md): plan y aceptación |
| 05 | 28/10/2026 | Despliegue | [Despliegue](clases/05-despliegue.md): ambientes y recuperación |
| 06 | 30/10/2026 | Scrum | [Scrum](clases/06-scrum.md): backlog, objetivo y DoD |
| 07 | 02/11/2026 | Riesgos y datos | [Riesgos](clases/07-riesgos.md): matriz, relaciones y JOIN |
| 08 | 04/11/2026 | MVC | [MVC](clases/08-mvc.md): requisitos y filtro seguro |
| 09 | 06/11/2026 | Pruebas | [Entrega](clases/09-pruebas.md): pruebas y acta |

Cada sesión se plantea para 150 minutos: explicación, demostración, trabajo guiado y evidencia verificable. Consulte las diapositivas del ZIP para el itinerario original.
